Strelit UI Kit is a TypeScript docking and workspace layout library derived from the Golden Layout codebase and being modernized as a standalone product line.

# Features

- Native popup windows
- Touch support
- Support for application frameworks such as Angular and Vue
- Virtual components
- Comprehensive API
- Load and save layouts
- Focus components
- Completely themeable
- Works in modern browsers (Firefox, Chrome)
- Responsive design

# Installation / Usage

## Library (using npm)

The package metadata and public distribution strategy are still being finalized. For now, use the source repository directly and build locally.

## Source

Clone the repository and build locally.

To build the distribution locally, open a shell at the repository root and run the following commands:

1. `npm install` or `npm ci` (recommended) to install required dependencies
1. `npm run build` to generate the distribution (`dist` subfolder). This script will:
   - delete previous build artifacts
   - compile the TypeScript source
   - generate the rolled-up TypeScript declaration files
   - generate source maps
   - copy the style files to `dist`
1. Recursively copy the contents of `dist/css` to where your application can read them.

Note that the `lib` subfolder only holds intermediate TypeScript declaration files generated by the compiler.

## Build and run demo/test app

After installing the source, you can build and start the `apitest` demo app to view the library in action. Use the following commands:

- `npm run apitest:build` to build the demo
- `npm run apitest:serve` to start the development server.\
  You can then view it in your browser using the following link:\
  http://localhost:3000/

## Debugging the library

The `apitest` app can be used to debug the library. Its Vite configuration preserves source maps so debuggers can step through the TypeScript source.

If you wish to test the library with other applications, you can link to the repository without publishing to npm. Use the following steps:

1. Run the `npm link` from a shell in the strelit-ui-kit source repository top level folder.
1. Run `npm link strelit-ui-kit` from a shell in your application's top level folder.

Your application will then use the distribution in the repository `dist` subfolder. If you make library changes, rerun `npm run build`.

Run `npm install` to remove the npm link.

# Description

## Structure

The structure of a Strelit Layout object consists of its `LayoutManager` object and `ContentItem` objects which define the layout itself. See [Structure](./structure/index.md) for more details.

## Binding Components

Strelit Layout binds to components and then controls their position, size and visibility (positioning) so that they fit within a layout. There are several different ways in which Strelit Layout can bind to components. The easiest method is to register a component type and then specify that component type in a component's configuration.

See [Binding Components](./binding-components/index.md) for a full description of how Strelit Layout component binding works.

## Frameworks

Strelit Layout has been designed to work with JavaScript application frameworks such as Angular and Vue. Typically these types of frameworks wrap HTML elements with their own components. Instead of an application being a tree of HTML elements, it is a tree of framework components, each of which wrap an HTML element.

To support these frameworks, Strelit Layout implements 'Virtual Components'. This allows framework components to be embedded within Strelit Layout without having to use advanced framework techniques to allow the relevant framework component HTML elements to be displayed in a layout.

See [Frameworks](./frameworks/index.md) for a description and examples covering how to use Strelit Layout with JavaScript application frameworks.

## Sizing components

Within a layout structure, it is necessary to specify the size of `RowOrColumn` content items and their children. [More](./sizing-components/index.md).

## Layout resizing

A layout should normally resize to always fit within Strelit Layout's container element. This resizing can be configured to occur automatically or can be manually managed. [More](./layout-resizing/index.md)

## Component Focus

Components can have focus. This is analagous to HTML elements having focus. Only one component can have focus at any time. [More](./component-focus/index.md)

## Location Selectors

LocationSelectors specify the location of a component in terms of a parent and a index. They can be used when adding components programatically. [More](./location-selectors/index.md)

## Popouts

A component in a layout can be 'popped' out into a separate browser window. It can be then be viewed separately from the main layout. [More](./popouts/index.md)
